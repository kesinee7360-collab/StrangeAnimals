# Strange Animals (สัตว์โลกน่ารัก)
เว็บไซต์ศูนย์รวมข้อมูลสัตว์แปลก (Exotic Pets) ที่ให้ความรู้เกี่ยวกับการเลี้ยงดู กฎหมายข้อบังคับ และการติดต่อซื้อขายสำหรับคนรักสัตว์แปลก

## Project Objectives
**วัตถุประสงค์:** 
เพื่อเป็นแพลตฟอร์มสื่อกลางและศูนย์รวมข้อมูลที่ถูกต้องในการเลี้ยงดูสัตว์แปลก (Exotic Pets) รวมถึงให้ความรู้ด้านสวัสดิภาพสัตว์และกฎหมายที่เกี่ยวข้อง 
**กลุ่มเป้าหมาย:** 
ผู้ที่สนใจเริ่มต้นเลี้ยงสัตว์แปลก ผู้เลี้ยงมือใหม่ที่ต้องการคู่มือดูแล และผู้เพาะพันธุ์ที่ต้องการสร้างเครือข่าย

## Technology Stack
- **Design:** Figma
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Framework:** ไม่ใช้ Framework
- **CSS / UI:** เขียน CSS เองทั้งหมด (Vanilla CSS) ควบคุม Layout ด้วย Flexbox/Grid
- **Version Control:** Git และ GitHub
- **Hosting:** GitHub Pages
- **AI Tools:** Google Gemini

## Features
1. **หน้าแรก (Home):** นำเสนอวิสัยทัศน์ แบนเนอร์สวยงาม และรวมหมวดหมู่สัตว์เด่น
2. **ประเภทสัตว์ (Animal Types):** ระบบแสดงข้อมูลสัตว์แยกตามหมวดหมู่ (เช่น สัตว์เลี้ยงลูกด้วยนม, สัตว์เลื้อยคลาน ฯลฯ)
3. **ระบบ Modal Pop-up:** เมื่อคลิกที่การ์ดสัตว์ จะแสดงรายละเอียดเชิงลึก วิธีการเลี้ยงดู อุปกรณ์ และลักษณะพิเศษ โดยดึงข้อมูลจาก JavaScript (Data Array)
4. **กฎหมาย & ข้อห้าม (Laws):** แหล่งรวมข้อปฏิบัติตามกฎหมายสำหรับผู้เลี้ยง
5. **ติดต่อเรา (Contact):** ฟอร์มติดต่อและลิงก์โซเชียลมีเดีย

## Design Implementation
- **Layout:** นำโครงสร้างการจัดวางมาจาก Figma โดยเปลี่ยนจากการใช้ Absolute Positioning เป็นการใช้ CSS Flexbox และ Grid เพื่อให้มีความยืดหยุ่น 
- **Color:** คุมโทนสีตาม Design System ด้วยสีหลัก 3 สี ได้แก่ สีเขียวเข้ม (Primary Green: `#486a34`), สีแดงเข้ม (Primary Red: `#792220`) และสีขาว/ครีม (Background)
- **Typography:** ใช้ฟอนต์ **Kanit** จาก Google Fonts ตลอดทั้งเว็บไซต์เพื่อให้ดูทันสมัยและอ่านง่าย
- **Components:** พัฒนาการ์ดแสดงผล (Cards), ปุ่มแบบ Outline, และ Timeline Box ให้ตรงตามดีไซน์ต้นฉบับ

## Responsive Design
เว็บไซต์รองรับการแสดงผลทุกหน้าจอ โดยกำหนด Breakpoint ดังนี้:
- **Desktop (1200px ขึ้นไป):** แสดงเมนูด้านบนแนวนอนแบบเต็ม เลย์เอาต์ข้อมูลซ้าย-ขวา 
- **Tablet (Max-width: 1100px):** แถบเมนูด้านบน (Header) เปลี่ยนเป็นแนวตั้ง (Column) เพื่อป้องกันตัวหนังสือเบียดกัน
- **Mobile (Max-width: 768px):** 
  - ซ่อนเมนูด้านบน และใช้แถบเมนูด้านล่าง (Mobile Bottom Navigation) แบบแอปพลิเคชัน
  - เลย์เอาต์แบบซ้าย-ขวา (เช่น ในหน้าเกี่ยวกับเรา) ถูกบังคับให้เรียงต่อกันเป็นแนวตั้ง (Column) เพื่อประหยัดพื้นที่
  - ปรับขนาดฟอนต์ให้เล็กลงให้พอดีกับหน้าจอ
- **Small Mobile (Max-width: 480px):** ปรับขนาดโลโก้และการ์ดแสดงผลให้กระชับยิ่งขึ้น

## AI Usage
- **เครื่องมือ:** Google Gemini (DeepMind)
- **ขั้นตอนที่ใช้:** ใช้ช่วยในการวิเคราะห์และจัดโครงสร้าง Layout, การเขียนโค้ด CSS/JS และการ Debug ปัญหาการแสดงผล (Responsive)
- **ตัวอย่าง Prompt:** 
  1. "มันแสดงผลแปลกๆ" (แนบรูปหน้าจอมือถือที่ Layout พัง) เพื่อให้ AI ช่วย Debug
  2. "ให้หน้า ประเภทสัตว์ เมื่อกดตามหมวดหมู่ จะมีสัตว์ที่เกี่ยวข้อง... และเมื่อกดที่สัตว์ตัวนั้นก็จะขึ้นรายละเอียดด้วย" เพื่อวาง Logic ระบบแสดงผลสัตว์
  3. "ปุ่มในทำเป็นแบบ เอาท์ไลน์ หน่อย เพื่อความสวยงาม" เพื่อปรับสไตล์ UI ของปุ่ม
- **ผลลัพธ์ที่นำมาใช้ตรงๆ:** โค้ด HTML โครงสร้างพื้นฐาน, CSS Media Queries บางส่วน, โครงสร้างข้อมูล Data.js แบบ Array of Objects
- **ผลลัพธ์ที่ต้องแก้ไข:** AI เคยดึงรูปภาพแบบสุ่มที่แสดงผลผิดพลาด และเขียน Inline CSS ที่ทับซ้อนกับ Media Query 
- **การแก้ไข:** สั่งให้ AI จัดการปรับคีย์เวิร์ดดึงรูปภาพให้จำเพาะเจาะจงขึ้น และนำ Inline CSS ออกเพื่อย้ายไปเขียนใน `style.css` เป็นคลาสแทน 

## Deployment

## Challenges
- **ปัญหาที่พบ:** เลย์เอาต์ในหน้า "เกี่ยวกับเรา" เมื่อย่อหน้าจอเป็นมือถือแล้วรูปภาพกับตัวอักษรเบียดกันจนอ่านไม่ออก เนื่องจาก Inline Style (`flex-direction: row-reverse`) ไปขัดแย้งกับ Media Query
- **แนวทางแก้:** ลบ Inline Style ออก และหันไปใช้ CSS Class ควบคุมร่วมกับ Media Query เพื่อให้แสดงผลเรียงบน-ล่างได้อย่างถูกต้องเมื่ออยู่บนมือถือ
- **สิ่งที่เรียนรู้:** ได้เรียนรู้เรื่องลำดับความสำคัญของ CSS (Specificity) ว่า Inline Style มีอำนาจสูงสุดและทำให้การทำ Responsive พังได้หากไม่ระมัดระวัง รวมถึงได้ฝึกทักษะการสั่งงานและให้ AI ช่วย Debug
